# Updated game screenshots

Fresh captures from the current packaged build, October 29, 2026.

- Desktop: 1920 × 1080. Mobile: 390 × 844.
- Raised forest floor, clear bottom controls, slowly scrolling dark forest, Kaph lettering and current menus.
- Actual gameplay/screens: no composites, mockups, injected game state, mock leaderboard scores or score submissions.
- Real pointer/Burst input; seeded randomness and controlled browser time make the captures reproducible.
- Forest: Eder Muniz, used with credit and the original custom license. Other artists are credited in-game and in CREDITS.md.
- Earlier promotional covers/videos in screenshots/ remain unchanged.
- Reproduce after building: env -u NODE_OPTIONS node scripts/capture-updated-screenshots.mjs
